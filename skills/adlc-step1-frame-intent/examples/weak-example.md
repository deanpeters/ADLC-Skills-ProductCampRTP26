# Weak Example: Agent Intent Anti-Pattern

Synthetic anti-pattern. All details are invented for teaching.

## Artifact

The agent will automate support triage, improve efficiency, and make customers happier. It will read tickets, route them, and learn from results. Success is adoption by the support team.

## Why It Passes

It is short, plausible, and names a real workflow. A busy reviewer might accept it because it sounds aligned with the request.

## Why It Fails

It treats the agent as the outcome, blends recommendation and action, lacks an authority boundary, and offers adoption as success evidence without showing whether customers or operators are better served.

## Repair

Rewrite the brief around the human workflow, cap autonomy, name approval paths, and define behavior that would stop the effort before design.
