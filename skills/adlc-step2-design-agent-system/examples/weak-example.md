# Weak Example: System Map Anti-Pattern

Synthetic anti-pattern. All details are invented for teaching.

## Artifact

The agent connects to all support systems, learns from previous tickets, routes work automatically, and escalates when needed. Humans remain in the loop.

## Why It Passes

It sounds comprehensive and uses reassuring language about humans and escalation.

## Why It Fails

It names no system boundary, context source, memory rule, authority limit, reviewer, queue, or approval action. "All support systems" hides risk instead of designing it.

## Repair

Reduce the map to named context sources, named tools, allowed actions, blocked actions, and an explicit human handoff.
