# Reference

Shared public-facing doctrine for the ADLC skills lives here.

Keep this directory distinct from raw source capture. Use reviewed `findings/` synthesis and do not copy private source text, filenames, or manifests here.

## Contents

- [ADLC Glossary](glossary.md) - plain-language meanings for the software terms the ADLC uses.
- [Guided Context Capture](guided-context-capture.md) - the shared entry-mode contract every skill follows.
- [Minimum Viable Narrative](minimum-viable-narrative.md) - the shared definition of the one-person story canvas, its labelled action and response turns, the experience baseline every prompt carries, the portable prototype prompt format, and the build instruction, used by the narrative utility skill and inside Stage 4 for scenario cases.

Three related canvases are utility skills, because each ends in its own pivot, punt, or pursue decision: the [Agent Strategy Canvas](../skills/adlc-util-agent-strategy-canvas/SKILL.md) (between Stages 1 and 2), the [Solution Hypothesis](../skills/adlc-util-solution-hypothesis/SKILL.md) (between Stages 2 and 3), and the [Minimum Viable Narrative](../skills/adlc-util-minimum-viable-narrative/SKILL.md) (between Stages 3 and 4).
